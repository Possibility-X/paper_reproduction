# 实验与结果

建议使用 `<paper-id>/<experiment-id>/` 组织实验。提交配置文件、简洁的指标表、最终图表以及结论说明。

每个实验记录：

- 实验目的与对应论文表格或图。
- 复现代码和原项目的 commit SHA。
- 操作系统、硬件、运行环境和依赖版本。
- 数据来源、版本、校验值、预处理和数据划分。
- 随机种子、超参数和完整运行命令。
- 论文指标、复现指标、差异及可能原因。

大型中间产物放入实验目录下的 `runs/`、`outputs/`、`logs/` 或 `checkpoints/`，这些目录已忽略。需要长期保留的汇总指标和图表放入 `results/` 等可跟踪目录；大型文件另行存储并记录获取方式。
